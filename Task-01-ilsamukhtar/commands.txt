Project 1 - Linux & Command Line Basics
Commands Reference
========================================


1. pwd
Purpose: Displays the current working directory.


2. ls
Purpose: Lists files and directories in the current directory.


3. ls -l
Purpose: Displays files and directories in detailed/list format, including permissions, ownership, size, and modification time.


4. ls -a
Purpose: Displays all files, including hidden files.


5. ls -la
Purpose: Displays all files, including hidden files, in detailed format.


6. cd /path/to/directory
Purpose: Changes the current working directory to the specified location.


7. cd ..
Purpose: Moves one level up in the directory hierarchy.


8. cd ~
Purpose: Returns to the current user's home directory.


9. mkdir directory_name
Purpose: Creates a new directory.


10. mkdir -p parent/child/directory
Purpose: Creates nested directories, including parent directories if they do not already exist.


11. ls -R directory
Purpose: Recursively lists the contents of a directory and its subdirectories.


12. touch filename
Purpose: Creates a new empty file.


13. echo "text" > filename
Purpose: Creates a file or overwrites an existing file with the specified text.


14. echo "text" >> filename
Purpose: Appends the specified text to the end of an existing file.


15. cat filename
Purpose: Displays the complete contents of a file in the terminal.


16. less filename
Purpose: Opens a file for convenient page-by-page viewing.


17. head filename
Purpose: Displays the beginning portion of a file.


18. tail filename
Purpose: Displays the ending portion of a file.


19. tail -f filename
Purpose: Continuously monitors a file and displays new content as it is added.


20. cp source destination
Purpose: Copies a file or directory to another location.


21. mv old_name new_name
Purpose: Moves or renames a file or directory.


22. rm -i filename
Purpose: Safely removes a file after asking for confirmation.


23. rm -rf directory
Purpose: Recursively removes a directory and its contents.


24. ls -l filename
Purpose: Displays detailed information about a specific file, including its permissions and ownership.


25. chmod 754 filename
Purpose: Changes file permissions. The owner gets read, write, and execute permissions; the group gets read and execute permissions; others get read permission.


26. chown user:group filename
Purpose: Changes the owner and group associated with a file.


27. sudo mkdir -p /app/logs
Purpose: Creates the /app/logs directory structure with administrative privileges.


28. sudo touch /app/config.conf
Purpose: Creates the application configuration file /app/config.conf with administrative privileges.


29. echo "Started" | sudo tee /app/logs/server.log
Purpose: Creates the server log file and writes the initial "Started" message to it.


30. sudo ls -R /app
Purpose: Recursively verifies the complete /app directory structure.


31. sudo mv /app/logs/server.log /app/logs/server.bak
Purpose: Renames/backups the server.log file as server.bak.


32. sudo ls -l /app/config.conf
Purpose: Checks the permissions, ownership, size, and other details of the configuration file.


33. clear
Purpose: Clears the terminal screen for a cleaner workspace.


34. history
Purpose: Displays previously executed commands in the terminal.

Project 1 Practice Flow
========================================

Navigation:
pwd
ls -la
cd /tmp
pwd
cd ~
pwd

Directory Creation:
mkdir -p ~/decode-practice/app/src/main
ls -R ~/decode-practice

File Creation:
cd ~/decode-practice/app/src/main
touch index.html
echo "Hello DecodeLabs" > index.html
cat index.html

Copy and Move:
cp index.html backup.html
mv backup.html backup-final.html

Delete:
rm -i backup-final.html

Log Monitoring:
mkdir -p ~/decode-practice/logs
echo "Server Started" > ~/decode-practice/logs/server.log
tail -f ~/decode-practice/logs/server.log

Actual Project:
sudo mkdir -p /app/logs
sudo touch /app/config.conf
echo "Started" | sudo tee /app/logs/server.log
sudo ls -R /app
sudo mv /app/logs/server.log /app/logs/server.bak
sudo ls -l /app/config.conf
sudo ls -R /app

touch ~/decode-practice/test.txt

chmod 754 ~/decode-practice/test.txt
